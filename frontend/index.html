CodeSins Hackathon 2026 Core Honesty Doctrine

🛡️
Zero Code Execution Sandbox

Target project source files are strictly read as plain text and analyzed via Python's built-in ast.parse(). No scanned code is ever imported or run.

🎯
Zero Hallucinated Vulnerabilities

Advisories are grounded in verified OSV / PyPA identifiers or explicitly declared seed maps in symbol_map.json with honesty flags.

⚠️
Conservative Dynamic Hazard Flagging

Reflection (e.g. getattr(), eval(), wildcard imports) is never ignored; it conservatively yields UNCERTAIN with exact reasoning.

⚡
Deterministic BFS Call Graph

Reachability checks use pure graph mathematics: identical code always produces identical reachability proofs across test runs.
