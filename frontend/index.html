Hackathon 2026 Core Honesty Tenets

  • Strictly Zero Code Execution: Target project source code is never executed, imported, or run. All analysis is 100% static using Python's native ast.parse() text parsing.
  • No Hallucinated Findings: Vulnerable symbols are matched against verified OSV advisories or explicitly labelled curated fallbacks in symbol_map.json.
  • Conservative Uncertainty: Dynamic reflection hazards (such as getattr(), eval(), wildcard imports) are never swept under the rug — they conservatively yield UNCERTAIN with exact hazard reasons.
  • Deterministic BFS Graph Traversal: Reachability results are pure mathematical graphs; identical inputs always produce identical verdicts across test runs.
