# PyReach Evaluation Examples & Proof Artifacts

This directory contains deterministic sample outputs produced by the **PyReach** CLI and reachability engine when analyzing the three standard evaluation fixtures located in `tests/fixtures/`.

---

## Evaluation Fixtures Overview

Each fixture uses `pyyaml==5.3.1` (which is vulnerable to `PYSEC-2020-96` / `CVE-2020-14343` via unsafe `yaml.load` / `yaml.full_load` / `yaml.unsafe_load`):

| Fixture | Target Code Pattern | Expected Verdict | Confidence | Explanation |
| :--- | :--- | :---: | :---: | :--- |
| `tests/fixtures/reachable_app/` | `def run(): yaml.load(...)` | 🔴 `REACHABLE` | `high` | Static call chain from entry point `app.run` to `yaml.load` is proven. |
| `tests/fixtures/not_reachable_app/` | `def run(): yaml.safe_load(...)` | 🟢 `NOT_REACHABLE` | `medium` | Only safe API (`yaml.safe_load`) is called; no static path to vulnerable sinks exists and no dynamic hazards are present. |
| `tests/fixtures/uncertain_app/` | `loader = getattr(yaml, "load"); loader(...)` | 🟡 `UNCERTAIN` | `low` | Reflection (`getattr()`) prevents static proof of non-reachability; flagged conservatively. |

---

## Artifact Descriptions

### 1. `reachable_sample_output.json`
- Generated by: `python -m backend.cli tests/fixtures/reachable_app --format json`
- Validated against the `ScanReport` Pydantic v2 schema.
- Features:
  - `verdict = "REACHABLE"`
  - `confidence = "high"`
  - `evidence`: Serialized with aliased keys `"from"` and `"to"`:
    ```json
    {
      "from": "app.run",
      "to": "yaml.load",
      "file": "app.py",
      "line": 4
    }
    ```

### 2. `not_reachable_sample_output.json`
- Generated by: `python -m backend.cli tests/fixtures/not_reachable_app --format json`
- Features:
  - `verdict = "NOT_REACHABLE"`
  - `confidence = "medium"`
  - `evidence = []`
  - Zero dynamic hazards or parse errors detected.

### 3. `uncertain_sample_output.json`
- Generated by: `python -m backend.cli tests/fixtures/uncertain_app --format json`
- Features:
  - `verdict = "UNCERTAIN"`
  - `confidence = "low"`
  - `uncertainty_reasons`: Contains exact location and reason for the dynamic hazard:
    `"Dynamic call hazard at app.py:4 (getattr): Dynamic reflection/execution call 'getattr()' at app.py:4"`

### 4. `github_pr_report_preview.md`
- Generated by: `python -m backend.cli tests/fixtures/reachable_app tests/fixtures/not_reachable_app tests/fixtures/uncertain_app --format markdown`
- Formatted specifically for GitHub Step Summaries and Pull Request bot comments.
- Includes summary counters, markdown tables, call chain visualizations, and actionable remediation callouts recommending `yaml.safe_load()`.

---

## Reproducing the Artifacts

Run the following command from the repository root:

```bash
# Generate all proof artifacts
python -m backend.cli tests/fixtures/reachable_app --format json -o examples/reachable_sample_output.json
python -m backend.cli tests/fixtures/not_reachable_app --format json -o examples/not_reachable_sample_output.json
python -m backend.cli tests/fixtures/uncertain_app --format json -o examples/uncertain_sample_output.json
python -m backend.cli tests/fixtures/reachable_app tests/fixtures/not_reachable_app tests/fixtures/uncertain_app --format markdown -o examples/github_pr_report_preview.md
```
